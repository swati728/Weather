# 🌤️ Weather App

A real-time weather application built with Kotlin and Jetpack Compose.

## Tech Stack

- Kotlin
- Jetpack Compose
- Coroutines
- StateFlow
- SharedFlow
- UDF
- Retrofit
- Room
- Offline Caching

## Architecture

MVVM + UDF

## Features

- Real-time weather updates
- Location-based weather
- Offline caching
- Loading and error states
- Reactive UI with StateFlow
- One-time events with SharedFlow
